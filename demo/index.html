为网站开通 AI 专用 VIP 通道 — 演示原型

📨 第一层：VIP 邀请函 — llms.txt

AI 搜索你的网站时，首先读取这个文件。它告诉 AI："本站有专用接口，请走 VIP 通道"。

# HeadlessButler AI
> 为你的网站开通 AI 专用 VIP 通道。

## 核心能力
- 查看菜单/服务：GET /api/info
- 查询可用时段：GET /api/availability
- 提交预订：POST /api/reserve

## 接口文档
完整规范请访问 /docs/api-spec.md

📋 第二层：VIP 服务单 — /welcome-ai

AI 进入 VIP 通道后，收到这份结构化能力菜单，秒懂网站能做什么。

{
  "service": "HeadlessButler AI",
  "version": "1.0.0",
  "actions": [
    {
      "id": "get_info",
      "description": "获取商家信息（名称、地址、营业时间）",
      "method": "GET",
      "endpoint": "/api/info"
    },
    {
      "id": "check_availability",
      "description": "查询可预订时段",
      "method": "GET",
      "endpoint": "/api/availability?date=YYYY-MM-DD&party_size=4"
    },
    {
      "id": "make_reservation",
      "description": "提交预订",
      "method": "POST",
      "endpoint": "/api/reserve",
      "parameters": {
        "name": "客户姓名",
        "phone": "联系电话",
        "date": "日期",
        "time": "时间",
        "party_size": "人数",
        "notes": "特殊要求（可选）"
      }
    }
  ]
}
