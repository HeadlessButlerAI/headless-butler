# HeadlessButler AI — 项目概述

## 一句话介绍

**为你的网站开通 AI 专用 VIP 通道。**

HeadlessButler AI 是一个开源的无头网站 AI 管家框架，让任何 AI Agent 都能像人类一样读懂、使用你的网站。

---

## 为什么需要 HeadlessButler？

### 背景：AI 正在成为新的"访客"

ChatGPT、Claude、Kimi、PageAgent... AI Agent 不再只是后台算法，它们正在像人类一样访问网站、理解内容、执行操作。

### 当前痛点

| 障碍 | 具体表现 |
|------|---------|
| 信息提取困难 | HTML 混杂内容和样式，AI 难以准确抽取关键信息 |
| 操作无法执行 | AI 理解网页内容后，无法点击按钮、填写表单 |
| 缺乏标准接口 | 每个网站交互方式不同，AI 无法通用化地"使用"一个网站 |

### 解决思路

与其让 AI "猜"怎么用你的网站，不如你**主动为 AI 铺好路**：提供一套标准化的、机器可读的接口，就像管家迎接客人一样。

> ⚠️ HeadlessButler 不是聊天机器人。  
> ✅ 它是你网站背后，**专门服务 AI 的"接待层"**。

---

## 核心架构：三层 VIP 通道

```
AI Agent（客人）
    │
    ├── 📨 第一层：邀请函 (llms.txt)
    │    AI 搜索引擎发现你的网站，知道这里"欢迎 AI"
    │
    ├── 📋 第二层：服务单 (/welcome-ai)
    │    列出所有 AI 可调用的操作，像菜单一样清晰
    │
    └── ⚡ 第三层：包间 (API 端点)
         AI 直接调用 RESTful API，完成查询、预订等操作
```

---

## 与现有方案的区别

| | 传统网站 | HeadlessButler 网站 |
|------|---------|-------------------|
| 面向对象 | 人类 | 人类 + AI Agent |
| AI 发现方式 | 爬虫爬 HTML | 读 llms.txt |
| AI 理解方式 | DOM/视觉解析 | 结构化 JSON API |
| AI 操作方式 | 模拟点击 | RESTful API 调用 |
| 扩展性 | 每次需要重写解析逻辑 | 一次接入，通用适配 |
